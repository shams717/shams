# My Python Project

This project is a simple Python application that demonstrates how to print "Hello, World!" to the console.

## Getting Started

To run this project, you need to have Python installed on your machine. You can download it from [python.org](https://www.python.org/downloads/).

### Running the Code

1. Clone the repository to your local machine:
   ```
   git clone https://github.com/yourusername/my-python-project.git
   ```

2. Navigate to the project directory:
   ```
   cd my-python-project
   ```

3. Run the Python script:
   ```
   python src/hello_world.py
   ```

You should see the output:
```
Hello, World!
```

## GitHub Actions

This project includes a GitHub Actions workflow that automatically runs the Python script whenever changes are pushed to the repository. The workflow is defined in the `.github/workflows/main.yml` file.
